# mad1-trek-management-project
In this project we will work on the implementations of flask, crud operations, python, sql to build a basic trek management project.

Starting with preparing models of this project including :-
User-which maintains the record of all users,admin,staff
Trek- it keeps details of all treks
Slots-it stores all slots of each treks
Staff-it maintains record of which staff is included in which slot of trek
Booking-it stores all booking details from each booking including user,slot of booking,date of booking etc.
Review-it stores reviews from different bookings

In this project admin can manage things like creating trek,editing  trek,creating trek slots,editing trek slots, approving staff , blacklisting them even admin can blacklist any user too .
Admin can view every user,staff  details,each trek details , assigned staff to different trek slots even can edit profile and change password or any user/staff or for himself.

Staff can view his all treks,upcoming assigned treks,completed treks , trek participants of his assigned trek slot edit his profile see any trek participant past bookings .

User can book a trek with filtering trek on the basis of cost,open booking trek,trek name,location,difficulty and even view all his unique treks performed , ongoing treks,completed treks ,edit his profile and password.

A blacklisted user or staff can not further proceed to his dashboard when they login after blacklisting .

They is so unauthorized access permitted like user cant see admin or staff dashboard and so on.
